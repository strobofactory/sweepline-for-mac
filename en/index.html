05 / FAQ

Frequently asked questions

Is it safe to delete files and can I restore them?

Sweepline does not permanently erase files It moves them to the macOS Trash You can review deletion targets before running cleanup and system locations that should not be removed such as /System and Xcode CoreSimulator are excluded from detection

Does Sweepline free memory or speed up my Mac?

No Sweepline focuses on finding unnecessary files that actually occupy disk space and reclaiming that storage It does not include memory optimization or performance boost features and the reclaimable capacity it displays is measured

Is it a one-time purchase and how many Macs can I use?

Sweepline is a ¥2,980 one-time purchase with no monthly or annual subscription One license can be used on up to two Macs If you replace a Mac you can deactivate the old Mac and use the same license key on the new one

Which Macs and macOS versions are supported?

Sweepline supports macOS 14 Sonoma and later on both Apple Silicon Macs and Intel Macs

How do download installation and updates work?

After purchase we email you a download link and license key Sweepline is Apple notarized and installs by moving the app from the DMG into your Applications folder New versions can be checked and installed from inside the app and updates are free

How are duplicate files detected and can I use Sweepline offline?

Duplicate files are compared by content using SHA-256 rather than filename and hard links are not treated as duplicates Internet access is required for initial license activation After that Sweepline can be used normally offline
